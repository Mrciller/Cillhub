Cillhub 3.7.1 is a security update for encrypted messages. The app now encrypts only for the key it has stored for a contact, never for a different one the server shows later, and it remembers who is in each encrypted conversation: a 1:1 conversation that suddenly has another member is refused, and a new group member must be accepted before anything is encrypted for them. A missing or unverifiable conversation key is no longer replaced by itself; compare security codes, then tap "Make a new key". Plain messages in an encrypted conversation are marked "Not encrypted".
