Windows

Installer (.exe): click More info, then Run anyway if SmartScreen warns on first launch. For instant zero-install startup and ultra-low audio latency, grab the Native Rust Windows portable binary (.exe or .zip).

Linux

AppImage: make it executable (chmod +x Cillhub-*.AppImage) and run it. Debian/Ubuntu: install the .deb with sudo apt install ./cillhub_*.deb. For ultra-low audio latency and instant startup, try the Native Rust client (.deb or portable .tar.gz).

On your phone

  1. Android 8 or newer: download the Android app and open it. Android asks once to allow installs from your browser. The app updates itself, delivers messages and calls in the background and works with Android Auto.
  2. iPhone/iPad (Safari): open this site, tap Share, then Add to Home Screen.

Run your own server

Host Cillhub for your team on any Linux machine with Docker. The installer downloads the signed server image from here, checks it, asks for your hostname and starts everything. Voice works out of the box with the built-in voice server (one UDP port).

curl -fsSLO {{HUB}}/download/server/install.sh
sh install.sh

At the end it prints the address of the setup page and a one-time setup code. On that page you name your server, create the admin account (with two-factor authentication) and choose a mode:

Standalone
Fully independent: your own accounts, nothing is shared with this hub. It only checks here for updates, and you can turn that off.
Connected
Linked to this hub with a link code from its admins: people sign in with their existing Cillhub account, your public servers can appear in the server directory, and they show up next to everyone's other servers.

Check the signature

Every server release is signed by Pascal Oraze. The installer verifies the signature before it loads anything and prints the key's fingerprint. It must be exactly this one:

b6b5344a3111599a11303ebf2f004f46397a5aa4d8256c3155ab3d3929755d65

Ed25519, SHA-256 of the public key. Updates from the admin dashboard are checked against the same key.
