Linux Quick Install

AppImage: make it executable (chmod +x Cillhub-*.AppImage) and run it. Debian/Ubuntu: install with sudo apt install ./cillhub_*.deb. For ultra-low audio latency and instant startup, try the Native Rust client (.deb or portable .tar.gz).

On your phone

  1. Android: download the Android app and open it. The app updates itself and delivers calls and messages in the background.
  2. iPhone/iPad (Safari) / Chrome: open this site and tap Share › Add to Home Screen or Install App.

Run your own node

Host Cillhub on any Linux machine with Docker. Voice and WebRTC SFU work immediately:

curl -fsSLO /download/server/install.sh
sh install.sh
